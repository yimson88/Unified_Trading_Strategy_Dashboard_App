# Unified Trading Strategy Dashboard App

This app combines three tools into one clean Streamlit dashboard:

1. SMC Market Structure Strategy
2. FX 15m Momentum Strategy
3. Manual Risk Calculator / Trade Journal

## Main Features

- Trading Strategy Toggle buttons
- Switch between SMC, FX 15m, and Manual Risk Calculator
- Live market price from yfinance/Yahoo Finance
- Strategy analysis
- Trade ticket and risk calculator
- Save trades to a shared journal
- Edit and delete saved trades
- Performance dashboard
- Clean color-coded tables

## Color Rules

- BUY = Green
- SELL = Red
- NEUTRAL = Orange
- WIN = Green
- LOSS = Red
- TIME OUT positive = Light green
- TIME OUT negative = Light red

## Run

Double-click:

run_everything.bat

## Note

Yahoo/yfinance prices may be delayed. Confirm final trade prices on your broker platform.
